# Changelog

## 0.2.0 — CS2 Dev Tools

Renamed from *Presidente Dev Tools* and generalised to the whole game.

- Browse and edit the **base game and every installed mod**, with a per-mod filter.
- **Entities:** inspect and edit any building, citizen, vehicle, road or company — every component and list — and find entities by component.
- **Inspect selected:** open whatever you clicked in the game.
- **Search by value** (numbers and text) as well as by name, optionally scoped to one object.
- **Pins are saved per city** and restored when it loads (entity pins stay session-only).
- **Presidente** controls are now an optional plugin, shown only when Presidente is installed.
- **API** (`CS2DevTools.Api`) for other mods and tools, used by the Cities II Agent Bridge.

## 0.1.0 — Presidente Dev Tools

- In-game panel to browse and edit the Presidente (HomelandSecurity) mod's state.
- Approval, moods, laws and money controls; explorer, search, pins and undo.
